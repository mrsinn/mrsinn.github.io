Logic Circuit Builder

How to use
• Add components and drag them by their title.
• Click an Input to toggle TRUE/FALSE.
• Oscillators automatically change every 2 seconds.
• Green = TRUE; Red = FALSE.
• Connect mode: click an output port, then an input port.
• Select a component and click Delete Selected or press Delete.
• Reset returns to a completely blank canvas.
Blank canvas — add components to begin.
